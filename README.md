# RideCast – biker events

List of biker events (bike weeks, club anniversaries, motorcycle shows) in Thailand and South-East Asia,
read by the RideCast app (🏍 Events button).

- `events.json` — updated every week (Monday) from public event calendars, including the
  « Thailand Bike Week Calendar » of the Siam Motorcycle Association (SMCA) Facebook group.
- Dates come from the organisers and may change: always check before riding.
- No personal data (phone numbers, contact names) is stored here.

Format: `{"updated","sources","events":[{"id","name","start","end","place","lat","lng","country","url","q"}]}`
